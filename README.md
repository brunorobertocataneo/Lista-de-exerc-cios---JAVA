# Lista de Exercícios de Java

Atividades numeradas para praticar lógica de programação em Java. Cada arquivo corresponde a um exercício.

## Exemplo · contagem de primos

[Atividade10.java](Atividade10.java) lê dez números inteiros e conta quantos são primos. Com o JDK instalado, execute na raiz:

```bash
javac Atividade10.java
java Atividade10
```
